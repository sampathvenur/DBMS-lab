# Library Database Schema and Queries

This repository demonstrates a library database schema and a set of SQL queries to retrieve, manipulate, and manage data. The schema includes tables for books, authors, publishers, library programs, copies, and lending information.

### 6. Table: `BOOK_LENDING`

#### Create Table Query:
```sql
CREATE TABLE BOOK_LENDING (
    BOOK_ID VARCHAR(20),
    PROGRAMME_ID VARCHAR(20),
    CARD_NO VARCHAR(20),
    DATE_OUT DATE,
    DUE_DATE DATE,
    PRIMARY KEY (PROGRAMME_ID, BOOK_ID, CARD_NO),
    FOREIGN KEY (BOOK_ID) REFERENCES BOOK(BOOK_ID) ON DELETE CASCADE,
    FOREIGN KEY (PROGRAMME_ID) REFERENCES LIBRARY_PROGRAMME(PROGRAMME_ID) ON DELETE CASCADE,
    CONSTRAINT CK1 CHECK (DUE_DATE > DATE_OUT)
);
```

### **Query 1**: Retrieve details of all books in the library - id, title, name of publisher, authors, number of copies in each Programme, etc.

**Query**:
```sql
SELECT B.book_id, 1p.programme_id, b.title, b.publisher_name, bc.no_of_copies, a.author_name 
FROM book b, book_authors a, book_copies bc, library_programme 1p 
WHERE b.book_id = a.book_id 
AND b.book_id = bc.book_id 
AND bc.programme_id = 1p.programme_id;
```
OR
```sql
SELECT b.book_id, title, publisher_name, author_name, no_of_copies 
FROM book b, book_authors a, book_copies bc 
WHERE b.book_id = bc.book_id 
AND b.book_id = a.book_id;
```

### **Query 2**: Get the particulars of borrowers who have borrowed more than 3 books, but from Jan 2023 to Jun 2023.

**Query**:
```sql
SELECT card_no 
FROM book_lending 
WHERE date_out BETWEEN '01-JAN-2023' AND '30-JUN-2023' 
GROUP BY card_no 
HAVING COUNT(*) >= 3;
```

### **Query 4**: Partition the BOOK table based on year of publication. Demonstarte its working with a simple query.

**Partitioned Table Creation**:
```sql
CREATE TABLE BOOK1 (
    BOOK_ID VARCHAR(20) PRIMARY KEY, 
    TITLE VARCHAR(40), 
    PUBLISHER_NAME VARCHAR(20),
    PUB_YEAR INT,
    CONSTRAINT fk_publisher FOREIGN KEY (PUBLISHER_NAME) REFERENCES PUBLISHER(NAME) ON DELETE CASCADE
) 
PARTITION BY RANGE(PUB_YEAR) (
    PARTITION P1 VALUES LESS THAN(2001),
    PARTITION P2 VALUES LESS THAN(2005),
    PARTITION P3 VALUES LESS THAN(2010),
    PARTITION P4 VALUES LESS THAN(MAXVALUE)
);
```

### **Query 5**: Create a view of all books and its number of copies that are currently available in the library.

**Query**:
```sql
CREATE VIEW available_book AS 
SELECT b.book_id, 
       b.title,  
       SUM(bc.no_of_copies) - (
           SELECT COUNT(*)                          
           FROM book_lending bl                          
           WHERE bl.book_id = b.book_id                          
           GROUP BY bl.book_id
       ) AS books_available  
FROM book b
JOIN book_copies bc ON b.book_id = bc.book_id
GROUP BY b.book_id, b.title;
```

**Retrieve View Data**:
```sql
SELECT * FROM AVAILABLE_BOOK;
```

**Output**:

|---------|-------|-----------------|
| B101    | DBMS  | 185             |
| B102    | AIML  | 198             |

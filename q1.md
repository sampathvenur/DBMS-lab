# Bank Database Management System  

This project involves creating and managing a **Bank Database** using SQL. The database includes four tables:  
1. **BRANCH**: Information about bank branches.  
2. **CUSTOMER**: Details of bank customers.  
3. **ACCOUNT**: Information about customer accounts.  
4. **LOAN**: Records of loans sanctioned to customers.  

---

## Database Schema 

### Table 1: BRANCH 
```sql
CREATE TABLE BRANCH (
    BRANCH_ID VARCHAR(10),
    BANK_NAME VARCHAR(15),
    BRANCH_NAME VARCHAR(20),
    ASSETS INT NOT NULL,
    PRIMARY KEY(BRANCH_ID)
);
```
**Structure:**  
| Field       | Type          | Null | Key  | Extra          |  
|-------------|---------------|------|------|----------------|  
| BRANCH_ID   | VARCHAR(10)   | NO   | PRI  |                |  
| BANK_NAME   | VARCHAR(15)   | YES  |      |                |  
| BRANCH_NAME | VARCHAR(20)   | YES  |      |                |  
| ASSETS      | INT           | NO   |      |                |  

---

### Table 2: CUSTOMER  
```sql
CREATE TABLE CUSTOMER (
    CUSTOMER_ID VARCHAR(10),
    CUSTOMER_NAME VARCHAR(20),
    CUSTOMER_AGE INT,
    CUSTOMER_ADDRESS VARCHAR(20),
    CUSTOMER_PHONE INT,
    PRIMARY KEY(CUSTOMER_ID)
);
```
**Structure:**  
| Field           | Type          | Null | Key  | Extra          |  
|------------------|---------------|------|------|----------------|  
| CUSTOMER_ID      | VARCHAR(10)   | NO   | PRI  |                |  
| CUSTOMER_NAME    | VARCHAR(20)   | YES  |      |                |  
| CUSTOMER_AGE     | INT           | YES  |      |                |  
| CUSTOMER_ADDRESS | VARCHAR(20)   | YES  |      |                |  
| CUSTOMER_PHONE   | INT           | YES  |      |                |  

---

### Table 3: ACCOUNT  
```sql
CREATE TABLE ACCOUNT (
    ACC_NO INT,
    BRANCH_ID VARCHAR(10),
    ACCOUNT_TYPE VARCHAR(10),
    ACCOUNT_BALANCE INT,
    CUSTOMER_ID VARCHAR(10),
    PRIMARY KEY(ACC_NO),
    FOREIGN KEY(BRANCH_ID) REFERENCES BRANCH(BRANCH_ID) ON DELETE CASCADE,
    FOREIGN KEY(CUSTOMER_ID) REFERENCES CUSTOMER(CUSTOMER_ID) ON DELETE CASCADE
);
```
**Structure:**  
| Field            | Type          | Null | Key  | Extra          |  
|-------------------|---------------|------|------|----------------|  
| ACC_NO           | INT           | NO   | PRI  |                |  
| BRANCH_ID        | VARCHAR(10)   | YES  | FOR  |                |  
| ACCOUNT_TYPE     | VARCHAR(10)   | YES  |      |                |  
| ACCOUNT_BALANCE  | INT           | YES  |      |                |  
| CUSTOMER_ID      | VARCHAR(10)   | YES  | FOR  |                |  

---

### Table 4: LOAN  
```sql
CREATE TABLE LOAN (
    LOAN_NUMBER VARCHAR(5),
    BRANCH_ID VARCHAR(10),
    AMOUNT INT,
    CUSTOMER_ID VARCHAR(10),
    PRIMARY KEY(LOAN_NUMBER),
    FOREIGN KEY(BRANCH_ID) REFERENCES BRANCH(BRANCH_ID) ON DELETE CASCADE,
    FOREIGN KEY(CUSTOMER_ID) REFERENCES CUSTOMER(CUSTOMER_ID) ON DELETE CASCADE
);
```
**Structure:**  
| Field        | Type          | Null | Key  | Extra          |  
|--------------|---------------|------|------|----------------|  
| LOAN_NUMBER  | VARCHAR(5)    | NO   | PRI  |                |  
| BRANCH_ID    | VARCHAR(10)   | YES  | FOR  |                |  
| AMOUNT       | INT           | YES  |      |                |  
| CUSTOMER_ID  | VARCHAR(10)   | YES  | FOR  |                |

## Queries and Outputs  

### Query 1: Find all the customers who have atleast one account at the "Mangaluru" branch.

```sql
SELECT C.CUSTOMER_ID, C.CUSTOMER_NAME 
FROM CUSTOMER C, ACCOUNT A, BRANCH B 
WHERE B.BRANCH_NAME = 'MANGALURU' 
AND B.BRANCH_ID = A.BRANCH_ID 
AND A.CUSTOMER_ID = C.CUSTOMER_ID;
```
**Output:**
| CUSTOMER_ID   | CUSTOMER_NAME  |  
|---------------|----------------|  
| C1            | RAVI           |  
| C1            | RAVI           |  
| C4            | ARPITHA        |  
| C3            | VARUN          |  

---

### Query 2: Find names of the depositors who have deposited highest amount among all the customers. 

```sql  
SELECT C.CUSTOMER_ID, C.CUSTOMER_NAME, A.ACCOUNT_BALANCE 
FROM CUSTOMER C, ACCOUNT A 
WHERE C.CUSTOMER_ID = A.CUSTOMER_ID 
AND ACCOUNT_BALANCE = (SELECT MAX(ACCOUNT_BALANCE) FROM ACCOUNT);
```
**Output:**  
| CUSTOMER_ID | CUSTOMER_NAME | ACCOUNT_BALANCE |  
|-------------|---------------|-----------------|  
| C5          | SACHIN        | 90000           |  

---

### Query 3: Retrieve the customer name and loan amount of a customer who borrowed a loan more than 5,00,000.

```sql
SELECT C.CUSTOMER_NAME C, L.AMOUNT 
FROM CUSTOMER C, LOAN L 
WHERE C.CUSTOMER_ID = L.CUSTOMER_ID 
AND AMOUNT > 500000;
```
**Output:**  
|    C    | AMOUNT |
|---------|--------|
| ARPITHA | 565000 |
| SACHIN  | 955000 |

---

### Query 4: Retrieve the details of bank branch with maximum and minimum assets among the various branches.

```sql
SELECT BANK_NAME, BRANCH_NAME, ASSETS 
FROM BRANCH 
WHERE ASSETS = (SELECT MAX(ASSETS) 
                FROM BRANCH) 
UNION 
SELECT BANK_NAME, BRANCH_NAME, ASSETS 
FROM BRANCH 
WHERE ASSETS = (SELECT MIN(ASSETS) 
                FROM BRANCH);
```
**Output:**  
|   BANK_NAME    | BRANCH_NAME |    ASSETS    |
|----------------|-------------|--------------|
| BANK OF BARODA | MANGALURU   |  70000000    | 
| UNION BANK     | DELHI       |  20000000    |

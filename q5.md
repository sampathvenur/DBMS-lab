# Airline Database Schema and SQL Queries

## Schema Description

### `FLIGHT` Table
This table stores the flight details.

```sql
CREATE TABLE FLIGHT(
    FLIGHT_NUM INT,
    SOURCE VARCHAR(20),
    DESTINATION VARCHAR(20),
    DISTANCE INT,
    DEPARTS VARCHAR(10),
    ARRIVES VARCHAR(10),
    PRICE INT,
    PRIMARY KEY(FLIGHT_NUM)
);
```

| Column Name  | Data Type    | Nullable | Key      |  
|--------------|--------------|----------|----------|  
| FLIGHT_NUM   | INT          | No       | Primary  |  
| SOURCE       | VARCHAR(20)  | Yes      |          |  
| DESTINATION  | VARCHAR(20)  | Yes      |          |  
| DISTANCE     | INT          | Yes      |          |  
| DEPARTS      | VARCHAR(10)  | Yes      |          |  
| ARRIVES      | VARCHAR(10)  | Yes      |          |  
| PRICE        | INT          | Yes      |          |  

### `EMPLOYEES` Table
This table stores the employee details.

```sql
CREATE TABLE EMPLOYEES(
    EID INT,
    ENAME VARCHAR(20),
    SALARY INT,
    PRIMARY KEY(EID)
);
```

| Column Name | Data Type    | Nullable | Key      |  
|-------------|--------------|----------|----------|  
| EID         | INT          | No       | Primary  |  
| ENAME       | VARCHAR(20)  | Yes      |          |  
| SALARY      | INT          | Yes      |          |  

### `AIRCRAFT` Table
This table stores the aircraft details.

```sql
CREATE TABLE AIRCRAFT(
    AID INT,
    ANAME VARCHAR(20),
    CRUISINGRANGE INT,
    PRIMARY KEY(AID)
);
```

| Column Name    | Data Type    | Nullable | Key      |  
|----------------|--------------|----------|----------|  
| AID            | INT          | No       | Primary  |  
| ANAME          | VARCHAR(20)  | Yes      |          |  
| CRUISINGRANGE  | INT          | Yes      |          |  

### `CERTIFIED` Table
This table stores the certified details.

```sql
CREATE TABLE CERTIFIED(
    EID INT,
    AID INT,
    PRIMARY KEY(EID, AID),
    FOREIGN KEY(EID) REFERENCES EMPLOYEES(EID),
    FOREIGN KEY(AID) REFERENCES AIRCRAFT(AID)
);
```

| Column Name | Data Type | Nullable | Key                              |  
|-------------|-----------|----------|----------------------------------|  
| EID         | INT       | No       | Primary, Foreign (EMPLOYEES.EID) |  
| AID         | INT       | No       | Primary, Foreign (AIRCRAFT.AID)  |

# SQL Queries 

## Query1: Find the names of aircraft such that all pilots certified to operate them have salaries more than Rs.80,000

```sql
SELECT DISTINCT a.aname 
FROM aircraft a, certified c, employees e
WHERE a.aid = c.aid
AND c.eid = e.eid
AND NOT EXISTS (SELECT *
                FROM employees e1
                WHERE e1.eid = e.eid
                AND e1.salary < 80000);
```

**Output:**

| ANAME        |  
|--------------|
| AIRBUS       |  
| BOEING       |
| JET01        |  
| AIRBUS380    |
| AIRCFRAT02   |
---

## Query2: For each pilot who is certified for more than three aircrafts, find the eid and the maximum cruising range of the aircraft for which she or he is certified.

```sql
SELECT c.eid, MAX(cruisingrange)
FROM certified c, aircraft a
WHERE c.aid = a.aid
GROUP BY c.eid
HAVING COUNT(*) > 3;
```

**Output:**

| EID | MAX(CRUISINGRANGE) |  
|-----|--------------------|  
| 1   | 8000               |
---

## Query3: Find the names of pilots whose salary is less than the price of the cheapest route from Bengaluru to Mumbai.

```sql
SELECT DISTINCT e.ename 
FROM employees e 
WHERE e.salary <= (SELECT MIN(f.price)
                    FROM flight f
                    WHERE f.source = 'BANGALORE'
                    AND f.Destination = 'MUMBAI')
```

**Output:**
| ENAME  |  
|--------|  
| AJAY   |
---

## Query4: Find the aids of all aircraft that can be used on routes from Bengaluru to New Delhi.

```sql
SELECT a.aid
FROM aircraft a 
WHERE a.cruisingrange > (SELECT MIN(f.distance)
                        FROM flight f 
                        WHERE f.source = 'BANGALORE'
                        AND f.Destination = 'DELHI');
```

**Output:**

| AID  |  
|------| 
| 378  |
---

## Query5: Find the employee name and salary earning second highest salary.

```sql
SELECT ename, salary
FROM employees
WHERE salary = (SELECT MAX(salary)
                FROM employees
                WHERE salary < (SELECT MAX(salary)
                                FROM employees));
```

**Output:**

| ENAME  | SALARY  |  
|--------|---------|  
| ARUN   | 90000   |

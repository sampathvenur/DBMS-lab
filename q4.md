# Company Database Schema and SQL Queries

## Schema Description

### `EMPLOYEE` Table
This table stores the employee details.

```sql
CREATE TABLE EMPLOYEE(
    EID INT PRIMARY KEY,
    NAME VARCHAR2(20),
    ADDRESS VARCHAR2(20),
    GENDER CHAR(1) CHECK(GENDER = 'M' OR GENDER = 'F'),
    SALARY NUMBER(6),
    SUPEREID INT,
    FOREIGN KEY (SUPEREID) REFERENCES EMPLOYEE(EID),
    DNO NUMBER
);
```

| Column Name | Data Type       | Nullable | Key      |  
|-------------|-----------------|----------|----------|  
| EID         | INT             | No       | Primary  |  
| NAME        | VARCHAR2(20)    | Yes      |          |  
| ADDRESS     | VARCHAR2(20)    | Yes      |          |  
| GENDER      | CHAR(1)         | Yes      | Check    |  
| SALARY      | NUMBER(6)       | Yes      |          |  
| SUPEREID    | INT             | Yes      | Foreign  |  
| DNO         | NUMBER          | Yes      |          |

### `DEPARTMENT` Table
This table stores the department and manager details.

```sql
CREATE TABLE DEPARTMENT(
    DNUM NUMBER(5) PRIMARY KEY,
    DNAME VARCHAR2(10),
    DMGR_ID INT,
    FOREIGN KEY(DMGR_ID) REFERENCES EMPLOYEE(EID),
    MGR_START_DATE DATE
);

ALTER TABLE EMPLOYEE ADD CONSTRAINT FK FOREIGN KEY(DNO) REFERENCES DEPARTMENT(DNUM);
```

### `DLOCATION` Table
This table stores the department locations.

```sql
CREATE TABLE DLOCATION(
    DNO INT,
    FOREIGN KEY(DNO) REFERENCES DEPARTMENT(DNUM),
    LOCATION VARCHAR2(10),
    PRIMARY KEY(DNO, LOCATION)
);
```

| Column Name | Data Type       | Nullable | Key              |  
|-------------|-----------------|----------|------------------|  
| DNO         | NUMBER          | No       | Primary, Foreign |  
| LOCATION    | VARCHAR2(10)    | No       | Primary          |

### `PROJECT` Table
This table stores the project details.

```sql
CREATE TABLE PROJECT(
    PNUM NUMBER(2) PRIMARY KEY,
    PNAME VARCHAR2(20),
    PLOCATION VARCHAR2(20),
    DNO NUMBER REFERENCES DEPARTMENT(DNUM)
);
```

| Column Name | Data Type       | Nullable | Key       |  
|-------------|-----------------|----------|-----------|  
| PNUM        | NUMBER(2)       | No       | Primary   |  
| PNAME       | VARCHAR2(20)    | Yes      |           |  
| PLOCATION   | VARCHAR2(20)    | Yes      |           |  
| DNO         | NUMBER          | Yes      | Foreign   |

### `WORKSON` Table
This table stores the workson details for employees.

```sql
CREATE TABLE WORKSON(
    EID NUMBER(5) REFERENCES EMPLOYEE(EID),
    PNO NUMBER(2) REFERENCES PROJECT(PNUM),
    HOURS NUMBER(5,2),
    PRIMARY KEY(EID, PNO)
);
```

| Column Name | Data Type       | Nullable | Key              |  
|-------------|-----------------|----------|------------------|  
| EID         | NUMBER(5)       | No       | Primary, Foreign |  
| PNO         | NUMBER(2)       | No       | Primary, Foreign |  
| HOURS       | NUMBER(5,2)     | Yes      |                  |

### `DEPENDENT` Table
This table stores the dependent details for employees.

```sql
CREATE TABLE DEPENDENT(
    EMP_ID INT,
    DEPENDENT_NAME VARCHAR2(12),
    GENDER VARCHAR2(5),
    BDATE DATE,
    RELATIONSHIP VARCHAR(12),
    PRIMARY KEY (EMP_ID),
    FOREIGN KEY(EMP_ID) REFERENCES EMPLOYEE(EID) ON DELETE CASCADE
);

```

| Column Name       | Data Type       | Nullable | Key              |  
|-------------------|-----------------|----------|------------------|  
| EMP_ID            | INT             | No       | Primary, Foreign |  
| DEPENDENT_NAME    | VARCHAR2(12)    | Yes      |                  |  
| GENDER            | VARCHAR2(5)     | Yes      |                  |  
| BDATE             | DATE            | Yes      |                  |  
| RELATIONSHIP      | VARCHAR2(12)    | Yes      |                  |

# SQL Queries 

## Query1: Make a list of all project numbers for projects that involve an employee whose name is "Rahul", either as a worker or as a manager of the department that controls the project.

```sql
SELECT pno
FROM workson
WHERE eid IN (SELECT eid
              FROM employee
              WHERE name='rahul')
UNION 
SELECT pnum
FROM project 
WHERE dno IN (SELECT dnum
              FROM department
              WHERE dmgr_id 
              IN (SELECT eid
                  FROM employee
                  WHERE name='rahul')
);
```

**Output:**

| PNO  |  
|------|  
| 1    |  
| 2    |  
| 4    |
| 5    |

## Query2: Show the resulting salaries if every employee working on the "IOT" project is given a 10 percent raise.

```sql
SELECT eid, name, salary, salary + 0.1 * salary 
AS updated_salary 
FROM employee 
WHERE Eid 
IN (SELECT Eid 
    FROM workson 
    WHERE pno 
    IN (SELECT pnum 
       FROM project 
       WHERE Pname='IOT')
);
```

**Output:**

| EID | NAME  | SALARY | UPDATED_SALARY |  
|-----|-------|--------|----------------|  
| 1   | RAHUL | 35000  | 38500          |  
| 2   | SAHANA| 35000  | 38500          |

## Query3: Find the sum of the salaries of all employees of the "Accounts" department, as well as the maximum salary, the minimum salary, and the average salary in this department.

```sql
SELECT SUM(salary), AVG(salary), MAX(salary), MIN(salary) 
FROM employee e, department d 
WHERE e.dno = d.dnum 
AND d.dname = 'Account';
```

**Output:**

## Query4: Retrieve the name for each employee who works on all the projects controlled by department number 5(use NOT EXISTS operators).

```sql
SELECT Eid, name 
FROM employee 
WHERE NOT EXISTS ((SELECT pnum 
                   FROM project 
                   WHERE dno = 5) 
MINUS (SELECT pno 
       FROM workson w 
       WHERE w.Eid = e.Eid)
);
```
OR

```sql
SELECT Eid, name  
FROM employee e  
WHERE NOT EXISTS (
    SELECT pnum
    FROM project
    WHERE dno = 5
    AND pnum NOT IN (
        SELECT pno
        FROM workson w
        WHERE w.Eid = e.Eid
    )
);
```

**Output:**

| EID | NAME   |  
|-----|--------|  
| 5   | SAJAAN |

## Query5: Create a view Dept_info that gives details of department name, Number of employees and total salary of each department.

```sql
CREATE VIEW dept_info(name, count_emp, sum_sal) 
AS SELECT d.dname, count(*), sum(salary) 
   FROM department d 
   INNER JOIN employee e 
   ON e.Dno = d.Dnum 
   GROUP BY d.Dname;

SELECT * FROM dept_info;
```

**Output:**

| NAME      | COUNT_EMP | SUM_SAL |  
|-----------|-----------|---------|  
| ISE       | 1         | 35000   |  
| CSE       | 1         | 35000   |

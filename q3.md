# College Database Schema and SQL Queries

## Schema Description

### `STUDENT` Table
This table stores the student details.

```sql
CREATE TABLE STUDENT(
    USN VARCHAR2(20), 
    SNAME VARCHAR2(10), 
    ADDRESS VARCHAR2(10), 
    PHONE NUMBER(10), 
    GENDER VARCHAR2(10), 
    PRIMARY KEY(USN)
);
```

| Column Name | Data Type       | Nullable | Key     |  
|-------------|-----------------|----------|---------|  
| USN         | VARCHAR2(20)    | No       | Primary |  
| SNAME       | VARCHAR2(10)    | Yes      |         |  
| ADDRESS     | VARCHAR2(10)    | Yes      |         |  
| PHONE       | NUMBER(10)      | Yes      |         |  
| GENDER      | VARCHAR2(10)    | Yes      |         |

### `SEMSEC` Table
This table stores the semester and section details.

```sql
CREATE TABLE SEMSEC(
    SSID NUMBER(5), 
    SEM NUMBER(2), 
    SECTION VARCHAR2(1), 
    PRIMARY KEY(SSID)
);
```

| Column Name | Data Type       | Nullable | Key     |  
|-------------|-----------------|----------|---------|  
| SSID        | NUMBER(5)       | No       | Primary |  
| SEM         | NUMBER(2)       | Yes      |         |  
| SECTION     | VARCHAR2(1)     | Yes      |         |

### `CLASS` Table
This table stores the student-class mapping.

```sql
CREATE TABLE CLASS(
    SSID NUMBER(5), 
    USN VARCHAR2(20), 
    PRIMARY KEY(USN), 
    FOREIGN KEY(SSID) REFERENCES SEMSEC(SSID), 
    FOREIGN KEY(USN) REFERENCES STUDENT(USN)
);
```

| Column Name | Data Type       | Nullable | Key              |  
|-------------|-----------------|----------|------------------|  
| SSID        | NUMBER(5)       | Yes      | Foreign          |  
| USN         | VARCHAR2(20)    | No       | Primary, Foreign |

### `SUBJECT` Table
This table stores the course details.

```sql
CREATE TABLE SUBJECT(
    SUBCODE VARCHAR2(7) PRIMARY KEY, 
    TITLE VARCHAR2(20), 
    SEM NUMBER(4), 
    CREDIT NUMBER(2)
);
```

| Column Name | Data Type       | Nullable | Key     |  
|-------------|-----------------|----------|---------|  
| SUBCODE     | VARCHAR2(7)     | No       | Primary |  
| TITLE       | VARCHAR2(20)    | Yes      |         |  
| SEM         | NUMBER(4)       | Yes      |         |  
| CREDIT      | NUMBER(2)       | Yes      |         |

### `IAMARKS` Table
This table stores the internal assessment marks for students.

```sql
CREATE TABLE IAMARKS(
    USN VARCHAR2(20), 
    SSID NUMBER(5), 
    SUBCODE VARCHAR2(7), 
    TEST1 NUMBER(3), 
    TEST2 NUMBER(3), 
    TEST3 NUMBER(3), 
    FINALIA NUMBER(3), 
    PRIMARY KEY(USN, SUBCODE, SSID), 
    FOREIGN KEY(USN) REFERENCES STUDENT(USN), 
    FOREIGN KEY(SUBCODE) REFERENCES SUBJECT(SUBCODE), 
    FOREIGN KEY(SSID) REFERENCES SEMSEC(SSID)
);
```

| Column Name | Data Type       | Nullable | Key              |  
|-------------|-----------------|----------|------------------|  
| USN         | VARCHAR2(20)    | No       | Primary, Foreign |  
| SSID        | NUMBER(5)       | No       | Primary, Foreign |  
| SUBCODE     | VARCHAR2(7)     | No       | Primary, Foreign |  
| TEST1       | NUMBER(3)       | Yes      |                  |  
| TEST2       | NUMBER(3)       | Yes      |                  |  
| TEST3       | NUMBER(3)       | Yes      |                  |  
| FINALIA     | NUMBER(3)       | Yes      |                  |

# SQL Queries 

## Query1: List all the student details studying in fourth semester "C" section.

```sql
SELECT A.*, B.SEM, B.SECTION 
FROM STUDENT A, SEMSEC B, CLASS C 
WHERE A.USN = C.USN 
AND B.SSID = C.SSID 
AND B.SEM = 4 
AND B.SECTION = 'C';
```

**Output:**

| USN          | SNAME    | ADDRESS   | PHONE  | GENDER | SSID | SEM | SECTION |  
|--------------|----------|-----------|--------|--------|------|-----|---------|  
| 4SF20IS109   | VARSHINI | BANTWAL   | 896523 | FEMALE | 2    | 4   | C       |

---

## Query2: Compute the total number of male and female students in each semester and in each section.

```sql
SELECT sem, section, gender, count(*) 
FROM student s, semsec s1, class c 
WHERE s.usn = c.usn 
AND s1.ssid = c.ssid 
GROUP BY (gender, sem, section) 
ORDER BY (sem);
```

**Output:**

| SEM | SECTION | GENDER | COUNT(*) |  
|-----|---------|--------|----------|  
| 4   | C       | FEMALE | 1        |  
| 5   | A       | FEMALE | 1        |  
| 8   | A       | MALE   | 1        |  
| 8   | B       | MALE   | 1        |  
| 8   | C       | MALE   | 1        |

## Query4: Calculate the FinalIA (average of three test marks) and compute the corresponding table for students.

```sql
UPDATE iamarks 
SET finalia = GREATEST((testT1 + test2), (testT1 + test3), (test3 + test2)) / 2;
```

## Query5: Categorize students based on the following criterion:  
- If `FinalIA` = 45 to 50, then `CAT` = "Outstanding".  
- If `FinalIA` = 40 to 45, then `CAT` = "Good".  
- If `FinalIA` = 30 to 40, then `CAT` = "Average".  
- If `FinalIA` < 30, then `CAT` = "Weak".  

This query gives details only for 8th semester students in sections A, B, and C.

```sql
SELECT usn, finalia, 
CASE 
WHEN finalia BETWEEN 45 AND 50 THEN 'OUTSTANDING'
WHEN finalia BETWEEN 40 AND 45 THEN 'GOOD'
WHEN finalia BETWEEN 30 AND 40 THEN 'AVERAGE'
WHEN finalia < 30 THEN 'WEAK'
END 
AS CATEGORY 
FROM iamarks i, semsec s 
WHERE i.ssid = s.ssid 
AND sem = 8 
AND section IN ('A', 'B', 'C');
```

**Output:**

| USN        | FINALIA | CATEGORY   |  
|------------|---------|------------|  
| 4SF20CD001 | 36.5    | AVERAGE    |  
| 4SF20CS088 | 37.5    | AVERAGE    |  
| 4SF20CS089 | 43.5    | GOOD       |  
| 4SF20IS109 | 27.5    | WEAK       |  
| 4SF20CS098 | 48.0    | OUTSTANDING|
```
